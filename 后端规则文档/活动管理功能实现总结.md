## 📋 功能概述

## ✅ 已实现功能

### 1. 核心功能（11个接口）

#### 活动管理
- ✅ **创建活动** - `POST /api/events`
- ✅ **获取活动列表** - `GET /api/events`（支持分页、筛选、搜索）
- ✅ **获取活动详情** - `GET /api/events/{eventId}`
- ✅ **更新活动** - `PUT /api/events/{eventId}`（仅创建者）
- ✅ **删除活动** - `DELETE /api/events/{eventId}`（仅创建者）

#### 活动参与
- ✅ **参加活动** - `POST /api/events/{eventId}/join`
- ✅ **取消参加** - `DELETE /api/events/{eventId}/join`
- ✅ **获取参与者列表** - `GET /api/events/{eventId}/participants`
- ✅ **检查是否已参加** - `GET /api/events/{eventId}/joined`

#### 用户活动
- ✅ **获取用户创建的活动** - `GET /api/events/user/{userId}/created`
- ✅ **获取用户参加的活动** - `GET /api/events/user/{userId}/joined`

### 2. 高级功能

#### 筛选和搜索
- ✅ 按状态筛选（UPCOMING/ONGOING/ENDED）
- ✅ 按分类筛选（观影团、影评征集、线下活动等）
- ✅ 关键词搜索（标题或描述）

#### 状态管理
- ✅ 活动状态自动管理
  - `UPCOMING`: 即将开始
  - `ONGOING`: 进行中
  - `ENDED`: 已结束

#### 参与人数管理
- ✅ 自动统计当前参与人数
- ✅ 最大参与人数限制
- ✅ 满员检查

#### 权限控制
- ✅ 只有创建者可以更新/删除活动
- ✅ 任何用户都可以查看活动
- ✅ 任何用户都可以参加活动
- ✅ 防止重复参加

## 🗄️ 数据库设计

### Event 表（活动表）
```sql
CREATE TABLE events (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    creator_id BIGINT NOT NULL,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    image_url VARCHAR(500),
    event_date DATETIME NOT NULL,
    location VARCHAR(200),
    current_participants INT NOT NULL DEFAULT 0,
    max_participants INT NOT NULL DEFAULT 100,
    status VARCHAR(20) NOT NULL DEFAULT 'UPCOMING',
    category VARCHAR(50),
    created_at DATETIME,
    updated_at DATETIME,
    INDEX idx_creator_id (creator_id),
    INDEX idx_event_date (event_date),
    INDEX idx_status (status),
    FOREIGN KEY (creator_id) REFERENCES users(id)
);
```

### EventParticipant 表（活动参与者表）
```sql
CREATE TABLE event_participants (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    event_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    joined_at DATETIME,
    UNIQUE KEY unique_event_user (event_id, user_id),
    INDEX idx_event_id (event_id),
    INDEX idx_user_id (user_id),
    FOREIGN KEY (event_id) REFERENCES events(id) ON DELETE CASCADE,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 🚀 前端使用示例

### 创建活动
```dart
Future<void> createEvent() async {
  // 1. 上传活动封面图
  String? coverFilename;
  if (coverImage != null) {
    coverFilename = await uploadImage(coverImage);
  }
  
  // 2. 创建活动
  final response = await http.post(
    Uri.parse('http://10.0.2.2:7070/api/events'),
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
    body: jsonEncode({
      'title': '《星际穿越》IMAX重映观影团',
      'description': '一起去看IMAX版星际穿越！',
      'imageUrl': coverFilename,
      'eventDate': '2026-03-15T19:30:00',
      'location': '北京国际影城IMAX厅',
      'maxParticipants': 80,
      'category': '观影团',
    }),
  );
}
```

### 获取活动列表
```dart
Future<List<Event>> getEvents({String? status, String? category}) async {
  String url = 'http://10.0.2.2:7070/api/events?page=0&size=20';
  if (status != null) url += '&status=$status';
  if (category != null) url += '&category=$category';
  
  final response = await http.get(
    Uri.parse(url),
    headers: {'Authorization': 'Bearer $token'},
  );
  
  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    return (data['data']['content'] as List)
        .map((json) => Event.fromJson(json))
        .toList();
  }
  throw Exception('Failed to load events');
}
```

### 参加活动
```dart
Future<void> joinEvent(int eventId) async {
  final response = await http.post(
    Uri.parse('http://10.0.2.2:7070/api/events/$eventId/join'),
    headers: {'Authorization': 'Bearer $token'},
  );
  
  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    print('参加成功，当前人数: ${data['data']['currentParticipants']}');
  }
}
```

## 📝 注意事项

1. **图片存储**: 活动封面图只存储文件名，前端需要拼接完整URL
2. **时间验证**: 创建活动时，活动时间必须是未来时间
3. **权限检查**: 更新和删除操作会检查用户权限
4. **并发控制**: 参加活动时会检查是否已满员
5. **级联删除**: 删除活动时会自动删除所有参与记录
