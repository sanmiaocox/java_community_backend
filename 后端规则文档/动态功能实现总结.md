## 📋 实现内容

### 1. 数据库改造

#### 1.1 动态表添加图片字段
```sql
ALTER TABLE feeds 
ADD COLUMN images TEXT DEFAULT NULL COMMENT '动态图片（JSON数组，最多4张）' 
AFTER content;
```

#### 1.2 重建点赞表（支持动态和评论点赞）
```sql
DROP TABLE IF EXISTS likes;

CREATE TABLE likes (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '点赞ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    target_type ENUM('FEED', 'COMMENT') NOT NULL COMMENT '点赞目标类型',
    target_id BIGINT NOT NULL COMMENT '目标ID（动态ID或评论ID）',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    UNIQUE KEY uk_user_target (user_id, target_type, target_id),
    INDEX idx_target (target_type, target_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='点赞表';
```

### 2. 实体类更新

#### 2.1 Feed实体
- 添加 `images` 字段（TEXT类型，存储JSON数组）
- 移除 `rating` 字段（不支持动态评分）
- 移除 `shareCount` 字段（不实现分享功能）
- 移除 `likes` 关系映射（点赞表改造后不需要）

#### 2.2 Like实体
- 改用 `targetType` 和 `targetId` 替代 `feed` 关系
- 支持 FEED 和 COMMENT 两种点赞类型
- 移除 `feed` 关系映射

## ✨ 核心功能特性

### 1. 首页动态流
- 只显示当前用户关注的人发布的动态
- 如果没有关注任何人，返回空列表
- 按发布时间倒序排列

### 2. 多图上传
- 支持最多4张图片
- 图片以JSON数组格式存储文件名
- 前端需要拼接完整URL显示

### 3. 关联功能
- 动态可以关联电影（使用本地数据库ID）
- 动态可以关联活动
- 也可以发布纯文字动态

### 4. 点赞功能
- 统一的点赞表设计，支持动态和评论点赞
- 防止重复点赞（唯一索引）
- 实时更新点赞数

### 5. 评论功能
- 支持对动态发表评论
- 评论可以被点赞
- 删除动态会级联删除评论

### 6. 性能优化
- 批量查询点赞状态，减少数据库查询
- 使用分页查询，避免一次加载过多数据
- 点赞数、评论数使用字段存储，避免实时统计

### 7. 数据一致性
- 点赞/取消点赞时，同步更新likeCount
- 发表/删除评论时，同步更新commentCount
- 删除动态时，级联删除评论和点赞
- 使用事务保证操作原子性

## 📝 重要说明

### 1. movieId是本地数据库ID
- **重要**：动态中的movieId是本地数据库的电影ID，不是tmdbId
- 前端需要先调用 POST /api/movies/save 保存电影到本地数据库
- 然后使用返回的本地ID发布动态

### 2. 图片处理
- 图片文件名存储在数据库（JSON数组格式）
- 前端需要拼接完整URL：`http://10.0.2.2:7070/uploads/{filename}`
- 最多支持4张图片

### 3. 首页动态流
- 只显示关注人的动态
- 需要先关注用户才能看到他们的动态
- 如果没有关注任何人，首页为空

### 4. 权限控制
- 只能删除自己的动态
- 只能删除自己的评论
- 所有接口都需要Token认证

## 🚀 使用流程

### 发布动态流程
1. （可选）上传图片：POST /api/upload/image
2. （可选）保存电影：POST /api/movies/save
3. 发布动态：POST /api/feeds

### 查看动态流程
1. 获取首页动态流：GET /api/feeds
2. 查看动态详情：GET /api/feeds/{feedId}
3. 查看评论列表：GET /api/feeds/{feedId}/comments

### 互动流程
1. 点赞动态：POST /api/feeds/{feedId}/like
2. 发表评论：POST /api/feeds/{feedId}/comments
3. 点赞评论：POST /api/comments/{commentId}/like
