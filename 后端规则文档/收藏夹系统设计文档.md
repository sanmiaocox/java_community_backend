## 功能概述

### 核心功能

1. **收藏夹管理**
   - 用户可以创建多个收藏夹
   - 支持两种类型：电影收藏夹(MOVIE)、活动收藏夹(EVENT)
   - 系统自动创建默认电影收藏夹和默认活动收藏夹

2. **收藏项管理**
   - 可以收藏电影和活动
   - 电影收藏夹只能收藏电影
   - 活动收藏夹只能收藏活动
   - 支持添加备注

3. **看过记录**
   - 独立的看过记录表（watched_movies），与收藏夹系统分离
   - 支持评分和观影笔记
   - 快速查询用户看过的电影

### 功能特点

- ✅ 支持多片单管理
- ✅ 收藏夹可设置公开/私密
- ✅ 系统收藏夹不可删除
- ✅ 防止重复收藏
- ✅ 自动统计收藏项数量
- ✅ 支持收藏电影和活动

## 数据库设计

### 表结构关系

```
users (用户表)
  ↓
collections (收藏夹表)
  ↓
favorites (收藏项表) → movies/events
  
users (用户表)
  ↓
watched_movies (看过记录表) → movies
```

### 1. collections (收藏夹表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| name | VARCHAR(100) | 收藏夹名称 |
| description | TEXT | 收藏夹描述 |
| type | ENUM | 类型：MOVIE/EVENT |
| is_system | BOOLEAN | 是否系统收藏夹 |
| is_public | BOOLEAN | 是否公开 |
| cover_image | VARCHAR(500) | 封面图片 |
| item_count | INT | 收藏项数量 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**收藏夹类型说明**：
- `MOVIE`: 电影收藏夹，只能收藏电影
- `EVENT`: 活动收藏夹，只能收藏活动

**注意**：看过功能使用独立的 `watched_movies` 表，不属于收藏夹系统

### 2. favorites (收藏项表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| collection_id | BIGINT | 收藏夹ID |
| item_type | ENUM | 收藏项类型：MOVIE/EVENT |
| item_id | BIGINT | 收藏项ID |
| movie_id | BIGINT | 电影ID（已废弃，兼容旧数据） |
| note | TEXT | 用户备注 |
| created_at | DATETIME | 创建时间 |

**唯一约束**: `(collection_id, item_type, item_id)` - 防止在同一收藏夹中重复收藏

### 3. watched_movies (看过记录表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| movie_id | BIGINT | 电影ID |
| watched_at | DATETIME | 标记看过时间 |
| rating | DECIMAL(2,1) | 用户评分(0.0-10.0) |
| note | TEXT | 观影笔记 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**唯一约束**: `(user_id, movie_id)` - 防止重复标记

## 业务逻辑

### 用户注册流程

```
1. 用户注册
   ↓
2. 创建用户记录
   ↓
3. 自动创建"默认电影收藏夹" (MOVIE类型)
   ↓
4. 自动创建"默认活动收藏夹" (EVENT类型)
```

### 收藏电影流程

```
1. 用户选择收藏夹
   ↓
2. 验证收藏夹类型（电影收藏夹只能收藏电影，活动收藏夹只能收藏活动）
   ↓
3. 检查是否已收藏
   ↓
4. 创建收藏项记录
   ↓
5. 更新收藏夹计数 +1
```

### 标记看过流程

```
1. 用户点击"看过"按钮
   ↓
2. 创建 watched_movies 记录（独立表，不关联收藏夹）
   ↓
3. 可以添加评分和观影笔记
```

### 权限控制

- **收藏夹访问**: 只能访问自己的收藏夹或公开的收藏夹
- **收藏夹修改**: 只能修改自己的收藏夹
- **系统收藏夹**: 不允许删除，不允许修改名称和类型
- **收藏项操作**: 只能操作自己收藏夹中的收藏项

## API接口

### 收藏夹管理

#### 1. 创建收藏夹
```http
POST /api/collections
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "我的科幻片单",
  "description": "收藏的科幻电影",
  "type": "PLAYLIST",
  "isPublic": true,
  "coverImage": "https://example.com/cover.jpg"
}
```

**响应**:
```json
{
  "id": 1,
  "userId": 1,
  "name": "我的科幻片单",
  "description": "收藏的科幻电影",
  "type": "PLAYLIST",
  "isSystem": false,
  "isPublic": true,
  "coverImage": "https://example.com/cover.jpg",
  "itemCount": 0,
  "createdAt": "2026-03-01T10:00:00",
  "updatedAt": "2026-03-01T10:00:00"
}
```

#### 2. 获取用户的所有收藏夹
```http
GET /api/collections
Authorization: Bearer {token}
```

#### 3. 获取指定类型的收藏夹
```http
GET /api/collections/type/{type}
Authorization: Bearer {token}
```

参数: `type` = PLAYLIST | MIXED | WATCHED

#### 4. 获取收藏夹详情
```http
GET /api/collections/{id}
Authorization: Bearer {token}
```

#### 5. 更新收藏夹
```http
PUT /api/collections/{id}
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "更新后的名称",
  "description": "更新后的描述",
  "isPublic": false,
  "coverImage": "https://example.com/new-cover.jpg"
}
```

#### 6. 删除收藏夹
```http
DELETE /api/collections/{id}
Authorization: Bearer {token}
```

注意: 系统收藏夹不允许删除

### 收藏项管理

#### 1. 添加收藏项
```http
POST /api/favorites
Authorization: Bearer {token}
Content-Type: application/json

{
  "collectionId": 1,
  "itemType": "MOVIE",
  "itemId": 100,
  "note": "非常喜欢这部电影"
}
```

**响应**:
```json
{
  "id": 1,
  "collectionId": 1,
  "itemType": "MOVIE",
  "itemId": 100,
  "note": "非常喜欢这部电影",
  "createdAt": "2026-03-01T10:00:00",
  "itemDetail": {
    "id": 100,
    "title": "盗梦空间",
    "posterUrl": "https://example.com/poster.jpg",
    "rating": 9.3,
    "year": "2010"
  }
}
```

#### 2. 获取收藏夹中的所有收藏项
```http
GET /api/favorites/collection/{collectionId}
Authorization: Bearer {token}
```

#### 3. 获取收藏夹中指定类型的收藏项
```http
GET /api/favorites/collection/{collectionId}/type/{itemType}
Authorization: Bearer {token}
```

参数: `itemType` = MOVIE | EVENT

#### 4. 移除收藏项
```http
DELETE /api/favorites/collection/{collectionId}/item/{itemType}/{itemId}
Authorization: Bearer {token}
```

#### 5. 检查是否已收藏
```http
GET /api/favorites/check/{itemType}/{itemId}
Authorization: Bearer {token}
```

**响应**:
```json
{
  "isFavorited": true
}
```

## 使用场景

### 场景1: 用户创建电影收藏夹

```
1. 用户创建收藏夹 "我的科幻片单" (MOVIE类型)
2. 浏览电影时，点击"添加到收藏夹"
3. 选择 "我的科幻片单"
4. 电影被添加到收藏夹中
```

### 场景2: 用户收藏活动

```
1. 用户浏览活动页面
2. 点击"收藏活动"
3. 选择收藏夹（必须是EVENT类型）
4. 活动被添加到收藏夹中
```

### 场景3: 用户标记电影为看过

```
1. 用户在电影详情页点击"看过"按钮
2. 系统创建 watched_movies 记录
3. 可选：同时添加到"看过的电影"系统收藏夹
4. 用户可以添加评分和观影笔记
```

### 场景4: 用户管理多个收藏夹

```
1. 用户创建多个电影收藏夹：
   - "科幻电影"
   - "悬疑电影"
   - "经典老片"
2. 用户创建多个活动收藏夹：
   - "观影活动"
   - "线下聚会"
3. 将不同内容添加到对应收藏夹
4. 可以将同一部电影添加到多个电影收藏夹
```

## 注意事项

1. **系统收藏夹**
   - 用户注册时自动创建
   - 不允许删除
   - 不允许修改名称和类型

2. **收藏夹类型限制**
   - PLAYLIST 只能收藏电影
   - MIXED 可以收藏电影和活动
   - WATCHED 是系统片单，通常不手动添加

3. **防重复机制**
   - 同一收藏夹中不能重复收藏同一项目
   - 同一用户不能重复标记同一电影为看过

4. **性能优化**
   - `item_count` 字段冗余存储，避免频繁COUNT查询
   - `watched_movies` 独立表，查询性能更优
   - 合理的索引设计

5. **权限控制**
   - 只能操作自己的收藏夹
   - 可以查看他人的公开收藏夹
   - 系统收藏夹有特殊限制
