```

feeds (动态表)
  ├─→ comments (评论表) [feed_id]
  └─→ likes (点赞表) [feed_id]
```

## ✅ 删除策略检查

### CASCADE（级联删除）- 适用场景

用于从属关系，主记录删除时，从属记录也应该删除：

| 主表 | 从表 | 说明 |
|------|------|------|
| users | feeds | 用户删除，其动态也删除 |
| users | comments | 用户删除，其评论也删除 |
| users | likes | 用户删除，其点赞也删除 |
| users | favorites | 用户删除，其收藏也删除 |
| users | event_participants | 用户删除，其活动参与也删除 |
| feeds | comments | 动态删除，其评论也删除 |
| feeds | likes | 动态删除，其点赞也删除 |
| movies | favorites | 电影删除，其收藏也删除 |
| events | event_participants | 活动删除，其参与记录也删除 |

### SET NULL（设为空）- 适用场景

用于引用关系，主记录删除时，从属记录保留但引用设为NULL：

| 主表 | 从表 | 字段 | 说明 |
|------|------|------|------|
| movies | feeds | movie_id | 电影删除，动态保留但不再关联电影 |
| movies | events | movie_id | 电影删除，活动保留但不再关联电影 |
| events | feeds | event_id | 活动删除，动态保留但不再关联活动 |
