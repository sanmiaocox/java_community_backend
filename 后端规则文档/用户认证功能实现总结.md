## 🗄️ 数据库操作指南

### 第一步：创建数据库

在Navicat中执行以下SQL：

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS final 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_0900_ai_ci;

-- 使用数据库
USE final;
```

### 第二步：创建用户表

```sql
-- 创建用户表
CREATE TABLE IF NOT EXISTS users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    phone VARCHAR(11) NOT NULL UNIQUE COMMENT '手机号',
    password VARCHAR(255) NOT NULL COMMENT '密码（加密）',
    avatar VARCHAR(500) DEFAULT NULL COMMENT '头像URL',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_username (username),
    INDEX idx_phone (phone)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='用户表';
```

### 第三步：验证表是否创建成功

```sql

```

## 🧪 Postman测试指南

### 测试1：用户注册

**接口**: `POST http://localhost:7070/api/auth/register`

**请求头**:
```
Content-Type: application/json
```

**请求体**:
```json
{
  "username": "张三",
  "phone": "13912345678",
  "password": "123456"
}

    "username": "张三",
    "phone": "13912345678",
    "avatar": null,
    "createdAt": "2026-02-27T10:30:00"
  }
}
```

### 测试2：用户登录

**接口**: `POST http://localhost:7070/api/auth/login`

**请求头**:
```
Content-Type: application/json
```

**请求体**:
```json
{
  "phone": "13912345678",
  "password": "123456"
}
```

**预期响应**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "张三",
      "phone": "13912345678",
      "avatar": null,

```

**重要**: 保存返回的Token，后续需要认证的接口都需要携带这个Token！

## 🔍 常见问题排查

### 问题1：项目启动失败

**可能原因**:
1. MySQL服务未启动
2. 数据库连接配置错误
3. Maven依赖下载失败

**解决方案**:
1. 启动MySQL服务
2. 检查 `application.properties` 中的数据库配置
3. 在IDEA中右键项目 → Maven → Reload Project

---

### 问题2：注册时提示"Communications link failure"

**原因**: 数据库连接失败

**解决方案**:
1. 确认MySQL服务已启动
2. 确认数据库名、用户名、密码正确
3. 确认端口号正确（默认3306）

---

### 问题3：注册成功但数据库中没有数据

**原因**: 表未创建或JPA配置错误

**解决方案**:
1. 在Navicat中执行建表SQL
2. 检查 `application.properties` 中的 `spring.jpa.hibernate.ddl-auto=update`
3. 查看控制台是否有SQL执行日志

---

### 问题4：登录时提示"手机号或密码错误"但确认密码正确

**原因**: 密码加密方式不一致

**解决方案**:
1. 确认注册时使用的是BCrypt加密
2. 删除测试数据，重新注册
3. 不要手动插入密码，使用注册接口

---

### 问题5：Postman测试时返回404

**原因**: 接口路径错误或Controller未加载

**解决方案**:
1. 检查URL是否正确
2. 确认项目已启动
3. 查看控制台是否有Controller加载日志

## 🎯 功能特点

### 1. 密码安全
- ✅ 使用BCrypt加密，不可逆
- ✅ 每次加密结果不同（加盐）
- ✅ 密码不以明文存储

### 2. 参数校验
- ✅ 用户名：2-50个字符
- ✅ 手机号：11位，1开头
- ✅ 密码：6-20个字符
- ✅ 自动返回校验错误信息

### 3. JWT Token
- ✅ 包含用户ID和用户名
- ✅ 有效期7天（可配置）
- ✅ 使用HS256算法签名
- ✅ 可以解析和验证

### 4. 异常处理
- ✅ 统一的错误响应格式
- ✅ 业务异常自动捕获
- ✅ 参数校验异常自动处理
- ✅ 友好的错误提示

## 📝 重要提醒

### 1. 数据库必须先创建

1. 创建数据库 `final`
2. 创建用户表 `users`

1. 先测试注册
