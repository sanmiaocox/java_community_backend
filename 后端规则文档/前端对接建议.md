## API对接建议

### 1. 网络请求封装

**建议**: 创建统一的API请求工具类

**当前状态**: 前端使用http包，但缺少统一封装

**建议实现**:

```dart
// lib/services/api_service.dart
import 'package:http/http.dart' as http;
import 'dart:convert';

class ApiService {
  static const String baseUrl = 'http://localhost:7070';
  
  // 统一的GET请求
  static Future<Map<String, dynamic>> get(String endpoint) async {
    final response = await http.get(
      Uri.parse('$baseUrl$endpoint'),
      headers: {'Content-Type': 'application/json'},
    );
    
    if (response.statusCode == 200) {
      return json.decode(response.body);
    } else {
      throw Exception('请求失败: ${response.statusCode}');
    }
  }
  
  // 统一的POST请求
  static Future<Map<String, dynamic>> post(
    String endpoint, 
    Map<String, dynamic> body
  ) async {
    final response = await http.post(
      Uri.parse('$baseUrl$endpoint'),
      headers: {'Content-Type': 'application/json'},
      body: json.encode(body),
    );
    
    if (response.statusCode == 200) {
      return json.decode(response.body);
    } else {
      throw Exception('请求失败: ${response.statusCode}');
    }
  }
}
```

**优先级**: 中

### 2. 响应数据解析

**建议**: 统一处理后端返回的ApiResponse格式

**后端响应格式**:
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

**建议实现**:

```dart
// lib/models/api_response.dart
class ApiResponse<T> {
  final int code;
  final String message;
  final T? data;
  
  ApiResponse({
    required this.code,
    required this.message,
    this.data,
  });
  
  factory ApiResponse.fromJson(
    Map<String, dynamic> json,
    T Function(dynamic) fromJsonT,
  ) {
    return ApiResponse(
      code: json['code'],
      message: json['message'],
      data: json['data'] != null ? fromJsonT(json['data']) : null,
    );
  }
  
  bool get isSuccess => code == 200;
}
```

**优先级**: 高

### 3. Token认证

**建议**: 添加JWT Token管理

**说明**: 后端将实现JWT认证，前端需要在请求头中携带Token

**建议实现**:

```dart
// lib/services/auth_service.dart
import 'package:shared_preferences/shared_preferences.dart';

class AuthService {
  static const String _tokenKey = 'auth_token';
  
  // 保存Token
  static Future<void> saveToken(String token) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_tokenKey, token);
  }
  
  // 获取Token
  static Future<String?> getToken() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(_tokenKey);
  }
  
  // 清除Token
  static Future<void> clearToken() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_tokenKey);
  }
  
  // 检查是否已登录
  static Future<bool> isLoggedIn() async {
    final token = await getToken();
    return token != null && token.isNotEmpty;
  }
}

// 修改ApiService，添加Token
class ApiService {
  static Future<Map<String, String>> _getHeaders() async {
    final headers = {'Content-Type': 'application/json'};
    final token = await AuthService.getToken();
    if (token != null) {
      headers['Authorization'] = 'Bearer $token';
    }
    return headers;
  }
  
  static Future<Map<String, dynamic>> get(String endpoint) async {
    final response = await http.get(
      Uri.parse('$baseUrl$endpoint'),
      headers: await _getHeaders(),
    );
    // ... 其他代码
  }
}
```

## 数据模型建议

### 1. 时间格式处理

**问题**: Mock数据使用 `timeAgo` 字符串，但后端返回 `createdAt` 时间戳

**建议**: 添加时间格式化工具类

```dart
// lib/utils/time_util.dart
class TimeUtil {
  static String getTimeAgo(DateTime dateTime) {
    final now = DateTime.now();
    final difference = now.difference(dateTime);
    
    if (difference.inSeconds < 60) {
      return '刚刚';
    } else if (difference.inMinutes < 60) {
      return '${difference.inMinutes}分钟前';
    } else if (difference.inHours < 24) {
      return '${difference.inHours}小时前';
    } else if (difference.inDays < 30) {
      return '${difference.inDays}天前';
    } else {
      return '${dateTime.year}-${dateTime.month.toString().padLeft(2, '0')}-${dateTime.day.toString().padLeft(2, '0')}';
    }
  }
}

// 在FeedItem模型中使用
class FeedItem {
  final DateTime createdAt;
  
  String get timeAgo => TimeUtil.getTimeAgo(createdAt);
}
```

**优先级**: 高

### 2. 数据模型字段对应

**建议**: 确保前端模型字段与后端一致

**后端字段** → **前端字段对应关系**:

| 后端字段 | 前端字段 | 类型 | 说明 |
|---------|---------|------|------|
| username | userName | String | 用户名 |
| avatar | userAvatar | String | 头像URL |
| createdAt | timeAgo | String | 需转换 |
| title | movieTitle | String | 电影标题 |
| posterUrl | moviePoster | String | 海报URL |
| likeCount | likes | int | 点赞数 |
| shareCount | shares | int | 分享数 |
| commentCount | - | int | 评论数 |

**建议**: 统一使用后端字段名，或在模型中添加 `fromJson` 方法进行转换

```dart
class FeedItem {
  final int id;
  final String username;
  final String avatar;
  final DateTime createdAt;
  final String content;
  final String? movieTitle;
  final String? moviePoster;
  final double? rating;
  final int? movieId;
  final int likeCount;
  final int shareCount;
  final int commentCount;
  
  // 兼容前端使用习惯的getter
  String get userName => username;
  String get userAvatar => avatar;
  String get timeAgo => TimeUtil.getTimeAgo(createdAt);
  int get likes => likeCount;
  int get shares => shareCount;
  
  factory FeedItem.fromJson(Map<String, dynamic> json) {
    return FeedItem(
      id: json['id'],
      username: json['user']['username'],
      avatar: json['user']['avatar'],
      createdAt: DateTime.parse(json['createdAt']),
      content: json['content'],
      movieTitle: json['movie']?['title'],
      moviePoster: json['movie']?['posterUrl'],
      rating: json['rating']?.toDouble(),
      movieId: json['movie']?['id'],
      likeCount: json['likeCount'],
      shareCount: json['shareCount'],
      commentCount: json['commentCount'],
    );
  }
}
```

**优先级**: 高

### 3. 分页加载

**建议**: 实现下拉刷新和上拉加载更多

```dart
class FeedListPage extends StatefulWidget {
  @override
  State<FeedListPage> createState() => _FeedListPageState();
}

class _FeedListPageState extends State<FeedListPage> {
  final List<FeedItem> _feeds = [];
  int _currentPage = 1;
  bool _isLoading = false;
  bool _hasMore = true;
  
  @override
  void initState() {
    super.initState();
    _loadFeeds();
  }
  
  Future<void> _loadFeeds() async {
    if (_isLoading || !_hasMore) return;
    
    setState(() => _isLoading = true);
    
    try {
      final response = await ApiService.get('/api/feeds?page=$_currentPage');
      final newFeeds = (response['data']['content'] as List)
          .map((json) => FeedItem.fromJson(json))
          .toList();
      
      setState(() {
        _feeds.addAll(newFeeds);
        _currentPage++;
        _hasMore = newFeeds.isNotEmpty;
        _isLoading = false;
      });
    } catch (e) {
      setState(() => _isLoading = false);
      // 显示错误提示
    }
  }
  
  @override
  Widget build(BuildContext context) {
    return RefreshIndicator(
      onRefresh: () async {
        _currentPage = 1;
        _feeds.clear();
        _hasMore = true;
        await _loadFeeds();
      },
      child: ListView.builder(
        itemCount: _feeds.length + (_hasMore ? 1 : 0),
        itemBuilder: (context, index) {
          if (index == _feeds.length) {
            _loadFeeds();
            return const LoadingWidget();
          }
          return FeedCard(feed: _feeds[index]);
        },
      ),
    );
  }
}
```

**优先级**: 高

## 状态管理建议

### 1. 使用Provider进行状态管理

**建议**: 引入Provider管理全局状态

```yaml
# pubspec.yaml
dependencies:
  provider: ^6.1.1
```

```dart
// lib/providers/user_provider.dart
import 'package:flutter/foundation.dart';

class UserProvider with ChangeNotifier {
  User? _currentUser;
  
  User? get currentUser => _currentUser;
  
  bool get isLoggedIn => _currentUser != null;
  
  void setUser(User user) {
    _currentUser = user;
    notifyListeners();
  }
  
  void logout() {
    _currentUser = null;
    AuthService.clearToken();
    notifyListeners();
  }
}

// main.dart
void main() {
  runApp(
    MultiProvider(
      providers: [
        ChangeNotifierProvider(create: (_) => UserProvider()),
      ],
      child: const MyApp(),
    ),
  );
}
```
