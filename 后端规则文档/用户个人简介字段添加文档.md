### 1. 添加更新个人资料接口

**接口设计**：
```
PUT /api/users/profile
```

**请求体**：
```json
{
  "username": "newusername",
  "avatar": "https://example.com/new-avatar.jpg",
  "bio": "这是我的新个人简介"
}
```

**实现代码**（建议）：

#### UpdateProfileRequest.java
```java
@Data
public class UpdateProfileRequest {
    
    @Size(min = 2, max = 50, message = "用户名长度必须在2-50之间")
    private String username;
    
    @Size(max = 500, message = "头像URL长度不能超过500")
    private String avatar;
    
    @Size(max = 500, message = "个人简介长度不能超过500")
    private String bio;
}
```

#### UserController.java
```java
@PutMapping("/profile")
public Result<UserInfoResponse> updateProfile(
    @RequestBody @Valid UpdateProfileRequest request,
    @RequestHeader("Authorization") String token
) {
    Long userId = jwtUtil.getUserIdFromToken(token);
    UserInfoResponse user = userService.updateProfile(userId, request);
    return Result.success(user);
}
```

#### UserService.java
```java
@Transactional
public UserInfoResponse updateProfile(Long userId, UpdateProfileRequest request) {
    User user = userRepository.findById(userId)
        .orElseThrow(() -> new BusinessException("用户不存在"));
    
    // 更新用户名（如果提供）
    if (request.getUsername() != null && !request.getUsername().equals(user.getUsername())) {
        if (userRepository.existsByUsername(request.getUsername())) {
            throw new BusinessException("用户名已存在");
        }
        user.setUsername(request.getUsername());
    }
    
    // 更新头像（如果提供）
    if (request.getAvatar() != null) {
        user.setAvatar(request.getAvatar());
    }
    
    // 更新个人简介（如果提供）
    if (request.getBio() != null) {
        user.setBio(request.getBio());
    }
    
    User savedUser = userRepository.save(user);
    return UserInfoResponse.fromEntity(savedUser);
}
```

## 📝 注意事项

1. **字段长度限制**：TEXT类型最大支持65535字符，如果需要更长的文本，可以使用MEDIUMTEXT或LONGTEXT
2. **前端显示**：建议前端显示时限制字数，超出部分显示"..."
3. **XSS防护**：如果个人简介支持HTML，需要做XSS过滤
4. **敏感词过滤**：建议添加敏感词过滤功能
5. **字数限制**：建议在前端和后端都添加字数限制（如500字）
